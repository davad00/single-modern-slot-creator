# Belladonna's Parlour

*"Every cure has a price."*

A poison-noir apothecary slot: 6×5 pays-anywhere with cascading bottle-breaks, essence-orb
multipliers that bank into the master vial across three forbidden chambers — **The Tasting**
(3 seals), **The Distillery** (4), **The Night Garden** (5+, with the prism doubler).
Generated by **single-modern-slot-creator v1.0.0** in one invocation (2026-08-08).

## Quick start

```powershell
# math: tests + reproduce any report (see docs/par-sheet.md §10 for exact commands)
cd math; uv sync; uv run pytest -q
uv run python -m slot_math.simulate --config ..\math-config --rounds 100000 --seed 5252 --workers 3 --bet 100

# client: 195 tests incl. equivalence/recovery; dev server on the scenario bank
cd ..\client; bun install; bun run typecheck; bun test; bun run dev
```

Regenerate after ANY math change: `math-config/generate_math_config.py` (bundles) →
re-run the battery (math/run-battery.ps1) → `export_dev_bank.py` (client bank) →
`sync_display_configs.py` → `validate_run.py` (24-check sweep).

## Layout

- `docs/` — GDD, PAR sheet, tuning log (all misses), UI/motion/audio specs, style bible,
  validation report, compliance review, assumption/decision/risk logs, known limitations.
- `config/` — 15 schema-valid runtime/display configs (state machine, events, policies…).
- `math-config/` + `math/` — generated bundles (base + ante) and the uv engine
  (`scatter_round.py` is this game's round logic); `math/reports/` = frozen sim battery.
- `client/` — Bun + TypeScript client (pure manifest renderer; placeholder sprites);
  `client/scenarios/dev-bank.json` = 260 engine-generated committed rounds (DEV ONLY).
- `prompts/` — 56-asset art-prompt register, audio prompts, 2 runnable Blender scripts.
- `assets/art/blender/` — 11 real renders (vial turntable ×8, parlour parallax ×3).
  Other art is prompt-only: the imagegen backend was down for the whole run
  (docs/known-limitations.md #9); generation is a documented re-run.
